Harbor Collision Map Editor

Paint the walkable / blocked grid used by pathfind.js and movement. Left-drag = block, right-drag = clear. Edits export to collision-grid.json.

100%

How this works

  1. Red tiles are solid (blocked) — this is the actual collision box the player and pathfinding use.
  2. Blue/tan tiles are water and dock reference only, shown for context. They are not edited here.
  3. Left-drag to block tiles, right-drag to clear them. Click once to toggle a single tile.
  4. When you're happy, click Download collision-grid.json.
  5. Move the downloaded file into client/src/world/collision-grid.json, replacing the existing one. Refresh the game to see it live — no code changes needed.
The background image loads from ../client/public/assets/harbor-environment.png relative to this file. If it doesn't appear (e.g. you moved this file), use "Load background image…" and pick that PNG manually — the grid still works without it.
